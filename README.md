# Portfolio

A personal portfolio website showcasing my work as a junior frontend developer.

## Live Demo

[https://mhmd-242.vercel.app/](#)

## Built With

- HTML
- CSS

## Features

- Responsive design (mobile, tablet, desktop)
- Dark theme with animated grid hero section
- Smooth scroll navigation with fixed header
- Project showcase with live demo and source code links
- Contact form and social links
- Accessibility support (focus-visible states, aria attributes, reduced motion)

## Sections

- Hero — Introduction with call-to-action buttons
- About — Background and personal story
- Skills — Technologies and tools
- Projects — Featured work with links to demos and repositories
- Contact — Email, contact form, and social media links

## Project Structure

Portfolio/
